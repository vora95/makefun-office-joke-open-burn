One single-line office joke (132 characters), written by a deterministic program (`main.ts`, Node stdlib only, no network):

> I hit reply-all on a company-wide email, so now 400 strangers know my cat is called Muffin and what I really think of Karen from HR.

`main.ts` validates the entry (1–200 chars, single line, no trailing newline), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, and verifies the file on disk is byte-identical (sha256 logged).
